ECB demo transcript and limitations

MacroLab brings official macroeconomic data and econometric models into your browser.

Start with the existing Same ECB shock, pooled template. Here, Germany, France, Italy and Spain face the same identified monetary policy shock.

Run the analysis, then focus on two outcomes: real GDP and the price level. Use the existing country selector to compare Germany, France, Italy and Spain in turn, then switch between the GDP and price responses.

The horizontal axis shows quarters after the shock. Each line shows an estimated cumulative response, while the shaded bands show uncertainty. A tightening shock need not produce identical responses across countries, and a point estimate alone is not a firm conclusion.

These are conditional estimates. The shock is constructed using the template’s existing recursive identification, rather than a directly observed policy surprise. The bands do not include uncertainty from estimating that shock, and they do not establish statistically significant differences between countries.

Use the charts to explore a question, inspect the assumptions, and export the results. MacroLab runs the calculation locally, with no account or coding required.

Blue shading belongs to the pooled response: 68% pointwise intervals conditional on the estimated shock. Dashed curves show the selected country. The summary graphic is an illustration of exported estimates, rather than a new application feature.

Build demo transcript and limitations

Build your own macroeconomic analysis in MacroLab.

Start with a new custom analysis. Choose inflation as the outcome and unemployment as an explanatory variable.

Select linear regression and Canada. Your variables, model and country stay together on one screen.

Open Advanced to review the sample and model settings, then run the analysis.

Inspect the estimated coefficient, its confidence interval and the relationship chart. This describes an association, not a causal effect.

Now return to Build. Keep the variables and country, but choose rolling regression.

Set the window and run again. The new chart shows how the estimated relationship changes across successive samples.

Different methods answer different questions. Check the specification, sample and uncertainty before comparing results.

Finally, export the chart, download the numerical results, or save a reproducible Python script.

MacroLab keeps your choices, source information and model settings attached to the analysis.

This is a real screen recording using existing controls. The closing chart is the PNG exported from MacroLab. The regressions describe associations; they do not establish a causal effect.
