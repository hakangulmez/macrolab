# Changelog

## v1.0 — 23 October 2026, local release candidate

- Six templates: four accepted v0 examples plus common ECB shock and Türkiye
  exchange-rate pass-through, with lag-augmented HC1 local projections.
- Matched VAR/LP comparisons, shared-axis country panels, descriptive peak
  intervals and separate agreement counts for distinct estimands.
- Türkiye's headline is cumulative CPI divided by cumulative depreciation,
  with joint sandwich delta intervals; CPI and NEER responses remain secondary.
- Progressive ECB baseline rendering; full joint uncertainty stays on demand.
- Rounded chart ticks, geographic CPI/HICP labels, actual coefficient intervals,
  dynamic build/snapshot labels and self-contained PNG/CSV/Python exports.
- Live official-source snapshot `20261023-1634`; the accepted October 21 snapshot
  remains available for exact v0 regression. No source failures or new stale flags.
- PCPS indices, ECB DFR/MRO and official SA EA HICP retain reviewed attribution.
  Country narratives and Pink Sheet stay excluded. No publication in this gate.

Finite-sample coverage limitations, conditional generated-regressor uncertainty,
initial runtime preparation and the accepted v0 extended-VAR stability exception
remain disclosed. Country notes, historical-decomposition UI and further Türkiye
options are deferred to v1.1. v2/v3 methods remain planned.

## v0.4 — accepted P2/P3.1 release

Four validated templates, static browser estimation, EIA Brent replacing the
excluded Pink Sheet, MIT code licence with separate data terms, bundled fonts
and favicon. Frozen numerical results are the v0 regression baseline.
