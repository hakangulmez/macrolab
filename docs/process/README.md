# Development records

This directory contains historical development, review, audit and publication
records. A gate number identifies a stage of development, not an econometric
method or a software version. Statements such as “local only”, “planned” or
“awaiting approval” describe the state when that record was written.

For the current application, start with [Methods](../METHODS.md),
[Validation](../VALIDATION.md), the [validation cards](../models/README.md),
[data sources](../SOURCES.md) and [local reproduction](../LOCAL_BUILD.md).
Software attribution remains in [Software notices](../SOFTWARE_NOTICES.md).

The public source export contains only records cleared for redistribution.
Private review outputs, local paths, raw data, derived result arrays and review
screenshots remain excluded. Historical references to those local outputs are
provenance, not instructions to retrieve or publish them.
