# Software notices

MacroLab code uses the [MIT licence](../LICENSE). Data and data-derived outputs
have separate conditions in [DATA.md](../DATA.md); the code licence does not
replace those conditions.

The static application ships third-party licence and notice files under
`licences/`. Its [notice manifest](https://hakangulmez.github.io/macrolab/licences/manifest.json)
records their filenames, byte counts and SHA-256 hashes. JavaScript dependencies,
Pyodide, CPython and scientific wheels retain their own licences. Inter, IBM Plex
Mono and JetBrains Mono use the SIL Open Font License; the font notices are
included with the application.

See [runtime notices and source availability](../third_party/runtime/SOURCE_AVAILABILITY.md)
for the pinned runtime provenance. The [original packaging inventory](process/P1_SOFTWARE_NOTICES.md)
is retained as a development record, including its original versions and hashes.
It is historical evidence, not a new licence interpretation.
