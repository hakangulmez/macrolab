A real screen recording

Template → model run → response and interval.

Follow the existing Same ECB shock template. The recording shows the actual browser workflow with the common country window and conditional bands. It adds no new model or method.

Transcript

  1. Open the existing Same ECB shock template on Explore.
  2. In Advanced settings choose the common window across countries; retain the existing conditional band and one-standard-deviation shock.
  3. Select Run analysis. The calculations execute in the browser.
  4. Read Key facts, the specification and the GDP response. Choose Spain, then Germany; the same shock is used.
  5. The shaded area is a 68% pointwise conditional interval. It omits first-stage shock-estimation uncertainty and is not a country-difference test.
